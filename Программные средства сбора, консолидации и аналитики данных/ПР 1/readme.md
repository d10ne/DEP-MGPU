## Задачи варианта

1. **API.** Собрать вакансии с портала «Работа в России» (`opendata.trudvsem.ru`) по запросу «аналитик маркетплейсов» (4 страницы по 100 записей): пагинация, паузы, повторы запросов, обработка ошибок.
2. **HTML-парсинг.** Собрать каталог books.toscrape.com из категории Business (`business_35`, 3 страницы) двумя способами — BeautifulSoup (CSS) и XPath — и сверить результаты.
3. **RegEx.** Привести к числам и датам цены, остатки, рейтинги, зарплатные вилки, даты и навыки из текста вакансий; покрыть функции тестами.
4. **EDA и графики.** Распределение цен, медиана цены по рейтингу, доля товаров в наличии, boxplot зарплат.
5. **Выводы.** Рекомендации по ценовому позиционированию в нише и по найму под запуск направления.
6. **Задание со звёздочкой C.** Дедупликация вакансий: шинглы и коэффициент Жаккара.

Минимальный объём выборки — 50 записей API и 40 HTML-объектов. По параметрам варианта набралось 20 вакансий и 12 книг. Поэтому выборка расширена: к вакансиям добавлен запрос «маркетплейс», к книгам — категория Nonfiction как ценовой бенчмарк. Расширение описано в ноутбуке (шаг 1.2).

## Результат

- Собрано 198 вакансий и 72 книги: 81 запрос, 0 ошибок. Дата сбора — 17.10.2026.
- Медиана цены в нише Business — £33.63, в Nonfiction — £29.31 (+14,7 %).
- Медиана середины зарплатной вилки «ядра» команды (аналитики и специалисты маркетплейсов) — 62 500 руб.
- Самопроверка ноутбука: 11 из 11.
